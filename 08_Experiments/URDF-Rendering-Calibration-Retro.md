# URDF 渲染标定复盘:首次标定的弯路与必需参数清单

> 相关:[[03_Robotics/Perception/URDF-Rendering-Calibration|URDF 渲染几何标定方法]]、[[03_Robotics/Perception/Coordinate-Frames|机器人通用坐标系速查]]

## 1. 当天过程回顾

目标:用逐帧关节角驱动 URDF 渲染机械臂,投影与真实画面几何对齐(≤2~3px)。

实际路径(按时间顺序):

1. **搭建渲染链**:yourdfpy(FK)+ pyrender(EGL 离屏)跑通;数据侧发现早期 episode 一臂 state 全零,按 `state[t]=action[t-1]` 从 action 补齐。
2. **自由优化失败**:对每臂 6DoF 基座 + 内参做 Nelder-Mead/IoU 优化,连续踩坑:
   - IoU 目标被"罩住全图"的退化解 hack(mask 面积无限大);
   - fx/z 尺度歧义,fx 从 150~800 乱跑;
   - home 姿态(近零位)下基座偏航不可观测;
   - pyrender 的 `is_visible` 要设在 **mesh** 上而不是 node,否则"单臂渲染"实际是双臂,静默污染目标函数;
   - world→camera 平移写错(`t = -R·pos` 而非相机世界坐标),优化在错误空间里收敛;
   - 误读 URDF 零位姿态,给 joint2 加了 -π/2 偏移(实际数据零位 = URDF 零位,零位是 Link2/Link3 折叠态,joint3=0)。
3. **先验锚定后收敛**:补充实测先验(两基座内边距 55cm、底座 10cm 见方正朝向、相机位于两臂中点正上方斜照、home 时 Link1/2 不可见 joint4 可见、夹爪开口朝上)→ 改为**世界锚定参数化**(基座位置由实测锁定,只优化相机位姿 6DoF + fx + k1 + 共享偏航 θ0),加基座内边投影约束和方形像素约束(fx=fy),f0 帧双臂 IoU 达标。
4. **人工微调收尾**:在目视指导下微调偏航(例如左 +10°、右 -10°)与基座位置(y +7cm、z -4cm 等),f0 对齐通过。

**结论:优化技巧解决不了"欠约束"——实测锚点才是标定的前提。**

## 2. 必需参数清单与现场测量方法

下次标定(或换相机/换工位)前,**先测完以下参数再开机优化**:

### 2.1 相机内参(最优先,可消除 80% 的试错)

| 参数 | 测量方法 |
|---|---|
| fx, fy, cx, cy | 打印棋盘格/ChArUco 标定板,手持在画面各区域拍 15~20 张(覆盖四角和边缘,广角相机尤其要拍边缘),`cv2.calibrateCamera` 一次解出 |
| 畸变 k1, k2(, k3) | 同上,广角/短焦相机**必须**带畸变模型;例如 front 相机 k1≈-0.21(桶形),纯针孔模型在角落(两臂所在位置!)偏差可达数十像素 |

注意:848×480 这类非标分辨率,若是从传感器裁剪/缩放过,标定时要用**最终出图分辨率**拍。

### 2.2 相机外参(相对桌面系)

定义桌面坐标系:x 沿两臂基座连线、y 指向桌面深处、z 向上。用卷尺+角度尺直接量:

| 参数 | 测量方法 |
|---|---|
| 相机高度 | 镜头到桌面的垂直距离 |
| 相机水平位置 | 镜头在两臂基座连线方向上的投影位置(是否中点)、前后位置(相对基座线) |
| 俯仰角 | 手机水平仪贴相机外壳,或拍一张已知尺寸物体的照片反推 |

### 2.3 机械臂基座几何(本次最关键的先验)

| 参数 | 测量方法 |
|---|---|
| 两基座间距 | 卷尺量两底座**同名边**间距(内边-内边 或 中心-中心,记录清楚是哪种) |
| 底座尺寸与朝向 | 底座长宽(例如 10×10cm)、是否"正朝向"(边平行于桌边)、各自 yaw 是否一致(例如左+10°、右-10° 的微调提示两臂可能并不严格平行,应实测) |
| 基座相对桌边位置 | 底座前沿到桌边的距离(确定 y 坐标) |
| **URDF 原点在底座上的位置** | 本次 URDF base_link **不含**真实底座台(10cm 方台),需量 URDF base 原点(joint1 轴心)相对台面的高度——决定 z 偏移,本次靠目视调了 -4cm,应实测 |

### 2.4 关节数据约定(防止运动帧错位)

| 参数 | 测量方法 |
|---|---|
| 数据零位 = URDF 零位? | 把臂摆到 URDF 零位(或拍照记录 home),对比 parquet 读数。本次确认:零位=零位(折叠 home,joint3=0 两连杆折叠) |
| 每个关节的符号(sign) | 手动 jog 每个关节 ±,记录读数变化方向与实际运动方向,列一张 6×2 的符号表(双臂可能不同) |
| 编码器零位偏移(offset) | 本次遗留:一臂 f800 大角度帧显示 joint1 需 ~+0.4 rad 偏移;两臂编码器零点可能独立,需逐臂验证 |
| 夹爪映射 | 量夹爪全开/全闭的物理开口(mm)与对应 `gripper.pos` 读数,两点定线性映射(本次 grip 0.46~0.88 → paw 0~0.05m 是猜的) |

### 2.5 时间同步

| 参数 | 测量方法 |
|---|---|
| 关节角-视频帧延迟 | 录一段快速往复运动,对比视频中运动方向反转帧与数据中速度过零帧的差;LeRobot 时间戳理论对齐,但 action 移位补齐的集可能有 1 帧系统性延迟 |

## 3. 方法论教训

1. **欠约束优化必发散**:单帧 + 自由 6DoF×2 + 内参 = 尺度/偏航/退化三重歧义。先验锚点(实测尺寸)比优化器选择重要得多。
2. **home 姿态不适合标定偏航**:近零位时基座 yaw 几乎不可观测;应选 1~2 个大角度、少遮挡的帧联合优化。
3. **优化目标必须人工审核**:SAM 分割 mask 会把操作员手臂/物体分进来,直接当 target 会带偏优化;target mask 要 ROI 过滤 + 目视确认。
4. **小心"作弊自由度"**:fy 独立时会被优化器拉爆(fy/fx=2.4)来代偿几何错误——锁 fx=fy(方形像素)后真几何才浮现。
5. **优化前先 sanity check 渲染组件**:一个 `is_visible` 设错层级的 bug 让所有 IoU 失真,排查了数轮才发现。先单组件验证(mask 面积、左右分离度)再进优化循环。
6. **目视微调是有效的最后一步**:自动优化到 IoU≈0.6 后,领域专家(操作者)的"旋转 10°、下降 2cm"式指令比继续调目标函数快得多——标定工具应支持交互式微调。

## 4. 当前状态与遗留问题

**已完成**:
- 渲染链:yourdfpy(FK) + pyrender(离屏渲染) + 畸变 warp、parquet 加载 + action 补齐、独立渲染视频 + mask、叠加/扫描工具、世界锚定优化
- f0 帧几何标定通过:生成标定 JSON(例如 fx≈539, k1≈-0.21,含全部微调)

**遗留**:
- [ ] 运动帧验证:joint1 编码器偏移(一臂 ~+0.4 rad)待逐臂确认;joint2~6 符号在大角度下待验证
- [ ] 夹爪 grip_scale/grip_offset 是猜测值,需实测行程标定
- [ ] 关节角-视频时间戳延迟未验证(运动帧错位的一个可能来源)
- [ ] k2、cx/cy 未标定(固定图像中心)
- [ ] 标定是否跨 episode 稳定(相机微抖)未验证
- [ ] f0 对齐后尚未生成整集渲染视频做时序检查

## 5. 下次标定标准流程(建议)

1. 现场测量 §2.1~2.4 全部参数并记录 → 填入标定 JSON 作为初值
2. 选 1 个 home 帧 + 2 个大角度少遮挡 帧,SAM 分割 + 人工审核 target
3. 世界锚定优化(只允许小范围扰动)
4. 交互式目视微调(±偏航/平移指令)
5. 整集渲染视频时序检查(延迟/抖动)
6. 跨 episode 抽帧复核
