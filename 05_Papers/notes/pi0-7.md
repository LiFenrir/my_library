# π₀.₇: A Steerable Generalist Robotic Foundation Model with Emergent Capabilities

## 基本信息
- **作者**: Physical Intelligence Team (100+ 作者)
- **机构**: Physical Intelligence (pi.website)
- **链接**: [arXiv:2604.15483](https://arxiv.org/abs/2604.15483) | [PDF](https://www.pi.website/download/pi07.pdf) | [Blog](https://www.pi.website/blog/pi07)
- **发表**: arXiv, 2025
- **代码**: 未开源

## 研究背景与动机

机器人基础模型（特别是 VLA）虽然在规模和能力上取得了显著进展，但其**组合泛化能力**（compositional generalization）仍然有限。与语言模型不同，现有 VLA 无法像 LLM 那样组合训练数据中的不同能力来解决新问题，甚至难以流畅执行训练时见过的指令。

核心挑战：如何从**大规模多样化数据**（包括不同策略、次优数据、失败案例、非机器人数据）中学习，而不导致模型对数据分布进行简单平均，产生次优结果？

## 核心方法

### 1. 多样化上下文条件（Diverse Context Conditioning）

π₀.₇ 的核心创新是在训练时为每个样本提供**丰富的多模态上下文**，不仅告诉模型"做什么"，还告诉它"怎么做"。

#### 上下文组成

| 组件 | 描述 | 训练时的作用 |
|------|------|-------------|
| **语言指令** $\ell_t$ | 整体任务描述（如"清理厨房"） | 定义任务目标 |
| **子任务指令** $\hat{\ell}_t$ | 中间语义子任务（如"打开冰箱门"） | 实现逐步语言指导 |
| **子目标图像** $\mathbf{g}_t$ | 多视角的近期未来状态图像 | 提供视觉执行细节 |
| **Episode 元数据** $m$ | 速度、质量评分、错误标记 | 区分数据质量和策略 |
| **控制模式** $c$ | joint / end-effector | 灵活选择控制方式 |

![[99_Attachments/papers/images/pi0-7/8e2b9c1396ec9ee5291927d37998d920391eccf58d5e13e1a2a802fc8a602980.jpg]]
*图 3: 提示概览。π₀.₇ 使用多种模态的上下文，包括子任务指令、子目标图像和 episode 元数据*

#### 完整 Prompt 示例
```
<Task: peel vegetables>
<Subtask: pick up the peeler>
<Speed: 8000>
<Quality: 5>
<Mistake: false>
<Control Mode: joint>
<Multi-view observation>
<Multi-view subgoals>
<Proprioception>
```

### 2. 子目标图像生成（World Model）

使用轻量级世界模型生成子目标图像，该模型基于 **BAGEL**（14B MoT 图像生成/编辑模型）初始化，并通过流匹配目标训练：

$$
\max_{\psi} \mathbb{E}_{\mathcal{D}_g} \left[ \mathcal{L}_{\mathrm{CFM}} \left(\mathbf{g}_t^\star, g_\psi(\mathbf{o}_t, \hat{\ell}_t, m)\right) \right]
$$

**关键设计**：
- 利用 web-scale 预训练获取语义和物理概念
- 通过子目标图像将非机器人数据（人类视频、网络数据）的知识迁移到机器人策略
- 运行时异步生成，每 4 秒或子任务变化时刷新

### 3. Episode 元数据

解决多样化数据中的质量歧义问题：

- **Overall speed**: 回合长度（离散化为 500 步区间）
- **Overall quality**: 1-5 分的执行质量评分
- **Mistake**: 动作段中是否发生错误

**训练时**：使用真实元数据标注
**测试时**：固定为高质量模式（speed=15th percentile, quality=5, mistake=false）

### 4. 训练时的 Dropout 策略

每个 prompt 组件随机 dropout，使模型能灵活处理任意子集：

| 组件 | Dropout 概率 | 说明 |
|------|-------------|------|
| 子目标图像 | 75% | 仅在 25% 样本中使用（加速训练） |
| 子任务指令（在有子目标时） | 30% | 视觉子目标可替代文本描述 |
| 元数据整体 | 15% | |
| 元数据各组件 | 5% | 速度/质量/错误分别 dropout |
| 控制模式 | 0% | 始终保留 |

### 5. 模型架构

![[99_Attachments/papers/images/pi0-7/8e70c5ce6241143ba5f7e28fc91033304c3da0632398fe44006620bc42ea3177.jpg]]
*图 2: 架构概览。π₀.₇ 是 5B 参数的 VLA，包含 4B VLM backbone、MEM 风格视频历史编码器和 860M 参数 action expert*

基于 π₀.₆ + MEM 记忆系统扩展：

| 组件 | 规模 | 说明 |
|------|------|------|
| VLM Backbone | 4B | Gemma3 初始化 |
| Vision Encoder | 400M | Gemma3 初始化，时序+空间压缩 |
| Action Expert | 860M | Flow Matching 目标 |
| **总计** | **~5B** | |

**关键架构特点**：
- MEM 风格的视频历史编码器：将多帧历史压缩为固定 token 数
- Block-causal masking：观测和子目标双向 attention，文本因果 attention
- 子目标图像通过相同 vision encoder 处理
- 实时 action chunking (RTC) 处理推理延迟

### 6. 训练数据

突破传统 VLA 仅使用高质量示教数据的范式：

- **人类示教数据**：多机器人平台、多环境（实验室/家庭/野外）
- **自主评估数据**：先前模型（π₀.₆*）RL 训练时的 rollout
- **人类干预数据**：策略执行中的人工干预
- **开源机器人数据集**
- **人类第一视角视频**
- **网络辅助数据**：物体定位、VQA、纯文本预测、视频-语言任务

## 关键创新点

1. **多样化提示策略**：受图像/视频生成中 prompt expansion 启发，将详细上下文引入机器人学习，使模型能从异构数据中学习而不退化

2. **Episode 元数据机制**：通过速度/质量/错误标签区分数据质量，使模型能从次优数据（包括失败案例）中学习，测试时通过元数据提示选择期望的行为模式

3. **子目标图像作为知识迁移桥梁**：利用世界模型生成的视觉子目标，将 web-scale 预训练知识（BAGEL）和非机器人数据有效迁移到机器人控制

4. **组合泛化的实证展示**：首次在机器人领域展示类似 LLM 的技能组合能力，包括零样本跨本体迁移、语言指导的新任务学习

5. **数据质量与规模的解耦**：证明通过丰富的上下文条件，模型可以从更大但平均质量更低的数据集中持续获益（传统方法会退化）

## 个人思考与启发

1. **"提示工程"在机器人学习中的价值**：π₀.₇ 将生成式 AI 中的 prompt expansion 思想引入机器人领域，证明详细的上下文条件不仅能提升性能，更是实现组合泛化的关键。这提示我们，机器人学习中的数据瓶颈可能不是数据量，而是**数据标注的丰富度**。

2. **元数据作为"行为模式选择器"**：Episode 元数据的设计非常巧妙——它不是简单地过滤低质量数据，而是让模型学会"在何种条件下选择何种行为"。这使得测试时可以通过元数据提示精确控制策略风格（快速/谨慎/高质量），类似于 LLM 中的 system prompt。

3. **子目标图像的知识迁移作用**：通过世界模型将非机器人数据（人类视频、网络图像）转化为机器人可消费的"视觉子目标"，是一种优雅的知识迁移机制。这比直接在动作空间对齐人类视频更可行。

4. **跨本体迁移的涌现策略**：π₀.₇ 在 UR5e 上发现的垂直抓取策略（与训练数据中的倾斜抓取不同）表明，模型真正理解了任务的本质，而非死记硬背运动轨迹。这是**物理智能**的重要标志。

5. **语言指导 → 自主能力的转化路径**：通过语言指导收集数据 → 训练高级策略 → 自主执行，这条路径为机器人学习提供了一种高效的新任务扩展方式，避免了昂贵的遥操作数据收集。

6. **局限性与未来方向**：
   - 零样本泛化成功率（~60%）仍低于分布内任务（>90%）
   - 在超大规模多样化数据中，严格区分"见过"与"未见过"任务变得困难
   - 未来可利用 π₀.₇ 的高可操控性进行测试时的强化学习微调
