# URDF 渲染几何标定方法

> 适用场景:已知逐帧关节角,用 URDF 渲染机械臂投影叠加到真实视频,要求几何对齐(静止帧边缘偏差 ≤2~3px,运动帧无可见错位)。
> 配套复盘:[[08_Experiments/URDF-Rendering-Calibration-Retro|首次标定踩坑记录]]
> 相关概念:[[03_Robotics/Perception/Coordinate-Frames|机器人通用坐标系速查]]

## 1. 问题定义与坐标系

标定 = 确定以下五组参数,使"关节角 → FK → 投影"与像素重合:

```
关节角 q (parquet, 弧度)
  → URDF FK(需要:关节符号 sign、零位偏移 offset、夹爪映射)
  → 连杆在 base 系位姿
  → T_world_base(需要:基座几何实测)
  → T_cam_world(需要:相机外参)
  → 针孔投影 + 径向畸变(需要:内参 fx/fy/cx/cy + k1/k2)
  → 像素
```

**坐标系约定**(示例):
- **世界系 = 桌面系**:x 沿两臂基座连线(左→右),y 指向桌面深处,z 向上
- **相机系**:OpenCV 约定(x 右、y 下、z 前);渲染器内部转 OpenGL
- **URDF base 系**:右手系,+z = joint1 轴;相对底座台有共享 yaw 偏置 θ0

## 2. 参数分层:先实测、再约束优化、最后目视微调

标定失败的第一原因是"让优化器求本来可以量的参数"。按可获得性分三层:

| 层 | 参数 | 获取方式 | 不做的后果 |
|---|---|---|---|
| **实测层** | 内参+畸变、相机高度/位置/俯仰、基座间距/尺寸/朝向、URDF 原点相对台面高度、关节符号表、夹爪行程 | 标定板、卷尺、水平仪、jog 关节 | fx/z 尺度歧义、偏航不可观测、退化解 |
| **优化层** | 外参残差(小范围)、θ0、k1 残差 | 世界锚定 + IoU 优化(Nelder-Mead) | — |
| **微调层** | 每臂 ±几° 偏航、±几 cm 平移、joint1 编码器偏移 | 专家目视指令("左臂逆时针 10°") | — |

## 3. 实测层:SOP

### 3.1 相机内参(最先做)

1. 打印棋盘格(9×6,格子 ≥20mm)或 ChArUco 板
2. 用**最终出图分辨率**(例如 848×480)拍 15~20 张:覆盖画面四角、边缘、不同距离和倾角(广角相机边缘信息决定畸变精度)
3. `cv2.calibrateCamera` 解出 K 和 k1,k2(,k3);重投影误差 <0.5px 合格
4. 验证:拍直边物体(桌边),畸变校正后应笔直

### 3.2 相机与基座几何(卷尺 15 分钟)

定义桌面系后逐项量:
- 相机:镜头到桌面垂直高度;镜头在基座连线方向的投影位置(是否中点);相对基座线的前后偏移;俯仰角(水平仪)
- 基座:两底座**同名边**间距(记清内边-内边还是中心-中心);底座长宽;朝向是否平行于桌边(两臂 yaw 是否真的一致);底座前沿到桌边距离
- **URDF 原点高度**:URDF base 原点(joint1 轴心)相对底座台面的 z 偏移——URDF 通常不含安装座,这项只能靠量

### 3.3 关节数据约定(防止运动帧错位)

1. **零位对照**:臂摆到 URDF 零位,拍照,对比 parquet 读数 → 得 offset
2. **符号表**:逐关节 jog ±5°,记录读数增减 vs 实际运动方向(从固定视角拍视频),列 6 关节 × 2 臂符号表
3. **夹爪**:卡尺量全开/全闭开口(mm),记对应 `gripper.pos` 读数,两点定线性映射
4. **时间同步**:录快速往复运动,视频运动反转帧 vs 数据速度过零帧的差 = 固定延迟

## 4. 优化层:世界锚定参数化

实测参数填入后,**基座位姿由实测锁死**,只优化:相机位姿 6DoF + θ0 + fx(锁 fy=fx)+ k1,加两类约束:

```
score = Σ_arm Σ_frames IoU(渲染mask, SAM分割mask)
        - λ · Σ_基座锚点 |投影x(基座边) - 实测像素x| / 200px
```

要点:
- **目标帧选择**:1 个 home 帧 + 1~2 个大角度少遮挡帧;home 帧单独标不定偏航
- **SAM target 必须 ROI 过滤 + 人工审核**(操作员手臂会被分进来,污染目标)
- **锁 fx=fy**(方形像素),否则 fy 被拉爆代偿几何错误
- **参数加边界**,防止"罩住全图"的 IoU 退化解
- 半分辨率优化提速,写回时还原

优化前应做 sanity check:渲染单臂 mask 面积、左右臂像素分离——pyrender 的 `is_visible` 要设在 mesh 上,node 上的会被静默忽略。

## 5. 微调层:专家目视指令

自动优化到 IoU≈0.6 后,换交互式微调比继续调目标函数快得多。标定工具应支持:
- 叠加渲染(半透明红)指定帧
- 接受"左臂世界系 +x 1cm / -z 2cm / 偏航 +10°"式指令直接改 JSON 重渲染
- 单参数 sweep 网格图一次出多张对比

微调用**世界系**描述(不是相机系),避免坐标系换算错误。

## 6. 验收标准

- [ ] 静止帧(home):渲染投影与真实臂边缘偏差 ≤2~3px,双臂
- [ ] 大角度帧:渲染臂尖端位置偏差 ≤10px,运动方向正确(关节符号/偏移正确的充要证据)
- [ ] 整集渲染视频:无可见时间延迟错位;无抖动(相机微抖检查)
- [ ] 跨 episode 抽 3~5 集复核(外参稳定性)

## 7. 失败模式速查

| 症状 | 根因 | 对策 |
|---|---|---|
| 优化后 mask 罩住全图 | IoU 退化解 | 参数加边界;检查初始解 |
| fx 撞到边界(150/800) | fx/z 尺度歧义,无实测锚点 | 补基座间距实测 |
| fy/fx > 1.5 | 优化器用 fy 代偿几何错误 | 锁 fx=fy |
| 静止帧对齐、运动帧错位 | 关节符号/编码器偏移错,或时间戳延迟 | jog 符号表;大角度帧逐关节排查;延迟测量 |
| 单臂渲染实际渲了双臂 | pyrender is_visible 设在 node 上 | 设在 mesh 上 |
| 两臂一正一镜像、一个能对准一个不能 | 共享 yaw/符号假设不成立(镜像安装≠镜像数据约定) | 逐臂独立验证符号与偏移 |
| 角落对齐、中心偏(或反之) | 畸变未建模 | 补 k1/k2,广角必须 |
